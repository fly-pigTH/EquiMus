# Dynamic Validation in Simulation

## Run
- cd in this directory, and run:

~~~bash
python scripts/sim_stance.py
python scripts/sim_swing.py
python scripts/stance_analysis.py
python scripts/swing_analysis.py
~~~

## Results

- `video/` records the dynamic response of both the stance and swing phases.
- `log/` shows the detailed logs of the simulation process (RMSE).
- `data/matlab_theo/` contains the theoretical data from MATLAB for comparison.
