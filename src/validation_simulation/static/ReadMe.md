# Static Validation in Simulation

## Run
- cd in this directory, and run:
~~~bash
python main.py
python video/conj_video.py
~~~

## Results

- The results will be saved in `data/` directory. See [data](./data/multi_exps_overall_error.csv) for result.
- `video/` records an demo of the simulation results of the static states in the working configurations.
- No log or figures
